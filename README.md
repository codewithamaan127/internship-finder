Internship Finder

Project Overview

Internship Finder is a responsive web application designed to help users explore internship opportunities across different domains. Users can search for internships and filter listings based on their preferred domain.

Features

- Search internships by company name, role, or location.
- Filter internships by domain.
- Display internship details in organised cards.
- Show a message when no matching internships are found.
- Responsive layout for mobile, tablet, and desktop screens.
- Keyboard-friendly navigation.

Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive design.
- JavaScript – Search, filtering, and dynamic content display.

Responsive Testing

The website was tested at:

- 360px – Mobile
- 768px – Tablet
- Desktop screen
